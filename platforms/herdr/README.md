# platforms/herdr

The adapter and mods that make solonaut work with [Herdr](https://herdr.dev). The first
platform, because it is the maintainer's daily driver.

What will live here:

- the adapter: focus a session's pane, open a visible session in a folder;
- mods: views inside Herdr that are clients of the core: Sessions, Inbox, Missions, Changes,
  Files, GitHub, the Houston chip and toasts, and Ground Control (a dashboard built from the
  other mods' widgets);
- the installer: a plan first, add-only tagged blocks, a backup, a confirmation, and a removal
  that gives the person's files back byte for byte.

Status: empty. Stage 3 of the [roadmap](../../ROADMAP.md).
